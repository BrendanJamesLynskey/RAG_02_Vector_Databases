# RAG 02 — Vector Databases

A detailed tour of approximate nearest-neighbour algorithms and vector database systems used in production RAG: HNSW graph construction and search parameters, IVF+PQ compression for 100M+ vector collections, scalar and binary quantisation, filtered search strategies, updates and snapshots, pgvector's IVFFLAT vs HNSW modes on Postgres, and a decision matrix comparing Qdrant, Weaviate, LanceDB, Pinecone, and Milvus.

**Live site:** https://brendanjameslynskey.github.io/RAG_02_Vector_Databases/
